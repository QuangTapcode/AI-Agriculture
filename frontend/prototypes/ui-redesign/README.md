# AgriAI UI redesign prototype

Prototype tạm thời để chọn hướng thiết kế. Ba phương án dùng chung một trang:

- `?variant=A` — Field Command
- `?variant=B` — Editorial Earth
- `?variant=C` — Glass Canopy

Chạy từ thư mục `frontend`:

```bash
npm run prototype:ui
```

Mở `http://127.0.0.1:4174/?variant=A`. Dùng nút nổi hoặc phím mũi tên trái/phải để đổi phương án.

Mọi thông số trong prototype đều là dữ liệu minh họa. Sau khi chọn hướng, xóa prototype và triển khai lại bằng component production có API thật.

Video duyệt nhanh của phương án A nằm tại `agriai-ui-motion-concept.mp4`.
